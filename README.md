## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte do curso Start na Programação da OneBitCode. O objetivo foi aprender os fundamentos de desenvolvimento web, utilizando HTML, CSS, e um pouco de JavaScript para criar uma página simples e funcional.

## 📝 Funcionalidades Principais
<li>Estruturação de conteúdo com HTML.
<li>Estilização com CSS.
<li>Interatividade básica com JavaScript para lidar com eventos do usuário.

## 🛠️ Tecnologias Utilizadas
<li>HTML5: Para criar a estrutura da página.
<li>CSS3: Para estilização.
<li>JavaScript: Para eventos e interatividade.
